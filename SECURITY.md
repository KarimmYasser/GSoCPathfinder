# Security Policy

## Reporting a Vulnerability

We take the security of GSoC Pathfinder seriously. If you find any security vulnerabilities or issues, please do not report them via public issues or pull requests. Instead, please report them responsibly.

### How to Report

Please report security issues by:
* Emailing the maintainer at: **karimmyasserr@gmail.com**
* Or using the **GitHub Private Vulnerability Reporting** feature on the repository if available.

In your report, please include:
1. A description of the vulnerability.
2. The impact of the vulnerability.
3. Steps to reproduce or a Proof of Concept (PoC).
4. Any potential mitigations you suggest.

### Scope

This security policy applies to all code in the GSoC Pathfinder repository, including:
- FastAPI backend server (`src/`)
- Rust scoring engine (`rust_engine/`)
- Vite-based frontend application (`frontend/`)
- Ingestion and database setup scripts

### Response & Remediation

Once a vulnerability report is received:
1. We will acknowledge receipt of your report within 48 hours.
2. We will investigate the issue and determine the appropriate fix.
3. We will keep you updated on our progress.
4. A fix will be developed and released.
5. Credit will be given to the reporter if desired.
